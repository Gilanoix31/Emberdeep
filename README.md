# Emberdeep

Pixel-art turn-based permadeath roguelike for Android, packaged with Capacitor.

Download the latest debug APK from the [v0.2.2 release](../../releases/tag/v0.2.2-debug).

## v0.2.2

- Full-screen 1080p-adaptive rendering that scales to the device display.
- Translucent MOBA-style touch overlay with a left analog joystick, right-side A interaction button, and quick bag wheel.
- Items are picked up by pressing A near them instead of by walking over them.
- Zelda-style free movement and Pokemon-style touch battle panel with FIGHT, MOVES, GUARD, and ITEM choices.
- Campaign objectives, endless mode, randomized gear bonuses, passive tree, evolutions, forge sets, and Ultra-rare Ultimate equipment.
- Cosmetic-only shop; no stat, gear, XP, or floor-skip purchases.

## Controls

| Action | Touch | Keyboard |
| --- | --- | --- |
| Explore | Left-side analog joystick | Arrows or WASD |
| Pick up nearby item | A button | E |
| Quick bag | BAG button | - |
| Battle choice | Tap FIGHT / MOVES / GUARD / ITEM | Arrows plus Space or Enter |
| Class skill | Tap MOVES, then the skill | K |
| Guard | Tap GUARD | G |
| Drink potion | Tap BAG, then POTION, or ITEM in battle | P |
| Menu | MENU | Escape |
