# Emberdeep

Pixel-art turn-based permadeath roguelike for Android, packaged with Capacitor.

Download the latest debug APK from the [v0.2.3 release](../../releases/tag/v0.2.3-debug).

## v0.2.3

- Full-screen 1080p-adaptive rendering with enlarged buttons, controls, and UI for easy viewing.
- Zoomed character-centered camera that explores the dungeon one labeled section at a time.
- On-screen map overview showing explored tiles, section grid, current section, viewport, foes, loot, stairs, and player marker.
- Translucent MOBA-style controls with a large left analog joystick, right-side A interaction button, and quick bag wheel.
- Zelda-style free movement and Pokemon-style touch battle panel with enlarged FIGHT, MOVES, GUARD, and ITEM choices.
- Campaign objectives, endless mode, randomized gear bonuses, passive tree, evolutions, forge sets, and Ultra-rare Ultimate equipment.
- Cosmetic-only shop; no stat, gear, XP, or floor-skip purchases.

## Controls

| Action | Touch | Keyboard |
| --- | --- | --- |
| Explore current section | Large left-side analog joystick | Arrows or WASD |
| View whole floor | On-screen minimap | - |
| Pick up nearby item | A button | E |
| Quick bag | BAG button | - |
| Battle choice | Tap FIGHT / MOVES / GUARD / ITEM | Arrows plus Space or Enter |
| Class skill | Tap MOVES, then the skill | K |
| Guard | Tap GUARD | G |
| Drink potion | Tap BAG, then POTION, or ITEM in battle | P |
| Menu | MENU | Escape |
